Images

    Output format

    Compression

    KB

    Per image. Works with JPEG and WebP; PNG can't hit a target by quality.

    Resize (optional)

    px

    Max width or height. Keeps aspect ratio. Blank = original size.

    File naming

    Single file keeps this name; multiple become image-1, image-2, …

    Separate downloads save each file on its own. Your browser may ask to allow multiple downloads.

    Images are processed on this device only. Re-encoding also removes embedded metadata (such as GPS/EXIF). HEIC and other formats a browser can't read are skipped.
